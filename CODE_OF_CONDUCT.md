# Code of Conduct

Dalang AI is made for children and families, so this project holds itself to the same care.

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

* Be kind and patient, in any language. Many contributors write in a second or third language.
* Respect Javanese and Indonesian culture and the people who keep wayang alive; disagree about details with
  sources, not mockery.
* No harassment, sexual content, personal attacks or sharing other people's private information.
* Never post children's recordings, names, faces or schools in issues, pull requests or screenshots.

Report problems to the maintainer, Ragil Artza Rozaksyah (Malik), through a private message on the repository
host. Reports are handled confidentially; maintainers may remove content or block accounts that break this code.
